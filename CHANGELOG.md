# Changelog

## 0.9.0-beta

First public beta.

* Full English text for the story, balloons, menus, items, missions, phone, shops, minigames and memo book.
* Most image text redrawn in English: pause menu, titles, tutorials (35 pages), minigame rule cards and results, ranking battle, game-over screen,
  stamps, fish guide, comic sound effects (romanised), staff roll with cast cards.
* Rebuilt Latin letters in the game font (proportional serif, same weight as the original) so balloons wrap into fewer, cleaner lines.
* English for hard-coded prompts in the executable (skip-scene prompt, exam terms, a few labels).
* Optional extras: New 3DS speed flags for Luma3DS (`exheader.bin`) and a per-game settings file for Azahar.
* Installer (`kb6_patcher.py`) that builds the mod files from your own decrypted dump and checks the game version first.
